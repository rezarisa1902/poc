Test 1 — Navigate-then-stop

Test 2 — Delayed meta/location redirect

Test 3 — history.replaceState path dressing

Same-origin only (can't change host), but dresses the path to read like a login URL. Tests how much of the bar the IAB shows.

Test 4 — Popup opener-URL spoof

Opens a blank popup and writes content into it; some IABs show the opener/!trusted URL for about:blank docs.

Watch for: popup bar shows a blank/opener URL, not the written content's origin.
